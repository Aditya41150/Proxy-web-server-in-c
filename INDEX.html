🔐 Configuration

Edit proxy.h to customize:

BUFFER_SIZE           8192  // Network buffer size
TIMEOUT_SEC             30  // Socket timeout
CACHE_SIZE             100  // Cache entries
MAX_CACHE_ENTRY_SIZE 65536  // Max response size

Then rebuild: make clean && make
